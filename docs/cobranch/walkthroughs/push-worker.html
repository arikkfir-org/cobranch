push-worker: everything a push sets in motion

The git-server commits a push and answers the client. The push worker then works out who wrote the commits and what the push means: issues to link, merges to record, runs, deliveries and reviews to queue, branch statuses to update. Nothing waits on it, so it can run any number of replicas, or none while no push waits.

The loop

Drain, then sleep until a notification or the poll

postgres.ListenPushes holds one connection outside the pool on LISTEN cobranch_pushes. A lost connection wakes the loop too, and the poll interval covers a missed notification.

One push

Claimed and processed in a single transaction

  • Claiming is a row lock. ClaimPush takes the push that has waited longest with FOR UPDATE SKIP LOCKED, so replicas never take the same one.
  • Attribution is by email. A commit's author and committer resolve to the user who holds the email verified, else a login-less user who holds it, else a new login-less user named after the commit. An email a user holds unverified is nobody.
  • Queues are locked in a fixed order, the delivery queue before the run queue before any branch, so two pushes to one repository cannot deadlock.
  • A failure rolls the whole push back and records it in a transaction of its own (FailPush), with a retry that waits longer after many failures than after the first.
  • The trace continues. The push carries its traceparent, and the worker links its span to it.

Worth a closer look

The orchestration lives in the store

followPush in adapters/postgres/git.go links issues, records merges, queues runs, deliveries and reviews, and updates branch status. That is the domain's most important sequence, written in the storage adapter. It is there for the single transaction; a service method driving a transactional port would say the same in the domain.

One push crosses five services' tables

The transaction writes what issues, jobs, code, delivery and reviewer own. Check each of those writes reuses its owner's query rather than a second copy.
