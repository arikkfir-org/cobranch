admin-server: running the installation

The Admin API the Back-office calls: organizations, users, limits, settings and identity providers, across the whole installation. It is the smallest API and the one an operator can keep off the public internet.

Things to know

Conventions it shares with the REST API

  • Every change needs If-Match. The service methods take a match argument, compared with the row's version, which trigger bump_version raises (PostgreSQL).
  • Lists page with an opaque cursor built in adminapi/api.go's page.
  • Entering an organization is an audited act with a stated reason, not a silent bypass: admin.Service.Enter.
  • Limits come in two layers: the installation's (chart values or settings) and one organization's override. services/limits works out which applies.
